o2h demo

o2h(config, data, { pipes, managers }) renders a builtIns.tree config (treeDefinition.js, a copy of assign-gingerly's tree-demo definition) against an API response (data/launch.json) to an HTML string, as a server would. This page runs it in the browser to show the result next to what builtIns.tree builds on the client from the same definition. What HTML can't carry (properties, event listeners, manager values) comes back as a residue, applied on the client with one assignFrom call.
