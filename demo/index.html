o2h demo

o2h(config, data, { pipes, managers }) renders a builtIns.tree config (treeDefinition.js, a copy of assign-gingerly's tree-demo definition) against an API response (data/launch.json) to an HTML string, as a server would. This page runs it in the browser to show the result next to what builtIns.tree builds on the client from the same definition. Elements that lost something HTML can't carry (properties, event listeners, managers) are marked data-pending, and o2h's opt-in default style (style: true) hides them, but only when scripts run. Hydrating restores them: builtIns.tree with adopt: true and the same config and data takes the server's elements over and removes the marks, and everything is live: try "Increase by one" on the left card afterwards.
