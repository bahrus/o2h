Adopt benchmark: adopt: true vs adopt: 'pending'

Each scenario is rendered once by o2h (in the page, as a server would), then hydrated many times from fresh copies of that HTML: builtIns.tree with adopt: true (bind everything) and with adopt: 'pending' (bind only what's marked data-pending, its contents and its ancestors). "Client render" is builtIns.tree building the same DOM from nothing, for scale. Times are medians per hydration; the parse (innerHTML) isn't counted. Query options: ?samples=21.
