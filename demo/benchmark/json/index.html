JSON loading: jank and total time

Each page loads demo/data/shoelace.json (~650 KB) one way, and reports when the data was ready, the main thread's own step, the longest gap between animation frames (jank, in every browser), and long tasks (Chromium only). Open each page in a fresh tab, or run node demo/benchmark/json/run.mjs for medians in Chromium, Firefox and WebKit.

Baseline: the same page with no data, for what page startup alone costs.

  1. fetch + response.json(), and fetch + text() + JSON.parse
  2. JSON embedded in <script type="application/json"> + JSON.parse (generate it first: node demo/benchmark/json/embed.mjs)
  3. a worker fetches and parses, and posts the object back; a worker fetches, parses and stores it in IndexedDB, and the page reads it (then the read alone, as on a repeat visit)
